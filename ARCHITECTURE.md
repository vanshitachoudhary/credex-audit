# Architecture — AI Spend Audit Tool

## 🧠 Overview

This system is a lightweight SaaS application that performs real-time AI tool spend analysis.

It follows a simple pipeline:

User Input → Normalization → Audit Engine → Recommendation Layer → UI Rendering

The system is intentionally designed to be **rule-based (not AI-driven)** for deterministic financial calculations.
